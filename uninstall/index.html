Localhost New Tab is removed.

One last step: the helper is still on your Mac.

Remove the helper and its data

Paste this in Terminal. It deletes the helper, its browser registrations and the ~/.localhost-new-tab folder.

curl -fsSL https://raw.githubusercontent.com/arcadie2k/localhost-new-tab/main/install.sh | sh -s -- --uninstall

Planning to come back?

Add --keep-history to the end of the command to keep your list of projects.

The helper is harmless if you leave it: Chrome only starts it for this extension. Thanks for trying it. Source on GitHub
